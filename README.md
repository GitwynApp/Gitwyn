## Work with git without leaving Xcode

Press <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>E</kbd> in any Xcode window to get started. Gitwyn opens right beside the code you're writing — no context switch, no separate app to manage.

---

## Features

### Stage exactly what you mean

Unstaged and staged, split cleanly side by side. Stage or discard a single hunk, watch the per-file counts update, and ship one clean commit — right beside the code you just wrote.

<img src="https://gitwyn.com/screenshot-staging.png" alt="Gitwyn staging view" width="100%" />

### Commit history

Browse the full commit graph with infinite scroll — complete messages, authors and branches, with a per-commit diff for every change. Search by message, author or hash, then branch, reset, cherry-pick or revert straight from the graph.

<img src="https://gitwyn.com/screenshot-commits.png" alt="Gitwyn commit graph" width="100%" />

### Every stash, named and waiting

Shelve work-in-progress with a real name and see exactly what's inside — files, hunks, add and delete counts. Apply, pop or drop from a list that actually tells you what you saved.

<img src="https://gitwyn.com/screenshot-stash.png" alt="Gitwyn stash history" width="100%" />
